🔒 Affable — Encrypt logic for the loader

Everything runs locally in your browser. Nothing is uploaded.

How to use
  1. Paste your full Test.user.js below (or pick the file).
  2. Type a password (remember it — the loader asks for it).
  3. Click Encrypt, then Copy output.
  4. Create a GitHub Gist, paste the output, save. Copy its Raw link.
  5. Put that raw link in the loader's PAYLOAD_URL.
